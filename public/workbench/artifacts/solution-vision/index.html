    Solution Vision¶

    用简短的 Elevator Pitch 表达一个初步的 Solution 方向，帮助参与者对齐愿景并看见分歧。它是 SO 塑形过程中的工作材料，不是完整的 Solution Outline，也不代表方案、收益或实施方式已经确定。

    表达模板¶

    面向 [目标对象]，在 [场景] 中遇到 [问题 / 需要 / 机会]，我们探索 [Solution 方向]，以帮助其 [目标行动 / 预期结果]。相较于 [当前做法 / 不作为 / 其他相关方向]，这一方向初步设想通过 [可能的改变] 改善现状。

    按需填写；如果方向、场景或差异还不清楚，写下当前理解和待对齐之处即可。不要为了填完整句子而假设或提前确定技术、Archetype、能力组合或实施方式。

    填写提示¶

    部分 提示
    目标对象与场景 谁在什么情境中遇到机会？场景可以先宽泛，后续在 SO 中选择和理解优先场景。
    问题 / 需要 / 机会 承接 Business Opportunity 的核心，不必重复整份 BO 记录。
    Solution 方向 用业务语言表达希望提供什么，不要求精确设计或技术方案。
    目标行动 / 预期结果 说明希望对象能做什么或改善什么；这是愿景主张，不是已验证收益。
    Unlike：现状或其他方向 可写当前做法、不作为的结果，或正在讨论的其他方向。它不只指竞品；这部分也为后续选择和理解场景提供线索。若尚不清楚，可留待探索。
    可能的改变 简要说明方向可能怎样改善现状；如只是初步推测，标明待验证，不写成事实。
